# 墨墨飼主測試指南

**飼主版・各養各的** · 對話機器人課程 · 2026-11-10

墨墨是一隻住在 LINE 裡的貓。加入後你會有一隻自己的墨墨。這份指南列出可以試的事、要傳的字，以及看到什麼時用「#」標註。

> 這是課堂研究用的原型。加入碼和 QR code 在課堂的投影畫面上，這份指南不含加入碼。

## 開始前：四件事

- **一次傳一句，等牠回了再傳**：墨墨一次只能回一個人，一輪要幾秒到十幾秒，全班一起傳時會排隊。好幾句連發，牠會當成同一輪一起讀。
- **等太久時傳「收」**：超過兩分鐘會收到「排隊中，前面還有 N 個人」。之後傳 `收` 拿回覆。
- **請用文字，不要用貼圖**：貼圖牠看不懂，只會回一聲貓叫加一個動作。
- **牠有自己的作息**：晚上大約 23:00 到早上 8:00 在睡。白天也可能午睡、躲起來或沒力氣，這些都是牠的狀態，不是故障。

## 領養你的墨墨

1. 掃投影畫面上的 QR code，加墨墨的 LINE 官方帳號為好友。會跳出一段自動訊息，**先不用回**。
2. 傳 `加入 碼`，例如 `加入 K7M3QP`。實際的碼看投影畫面，或由老師提供。
3. 讀完說明，願意就回 `同意`。
4. 傳 `我的身分` 確認，應該回「你是墨墨的飼主。」
5. 傳 `看看墨墨`，見見牠。

> 這是**你一個人的**墨墨：剛出生、還不認識你、沒有任何回憶，你是牠唯一的飼主。剛領養時牠還沒被照顧過，所以看起來沒什麼精神，這是正常的，第 1 步就是讓牠恢復。同學的墨墨是另一隻，你們互相看不到對方的墨墨和對話。如果加好友後已經回了「同意研究」，你也有自己的墨墨了，不用再傳加入碼。

## 測試步驟

建議照順序做。每一步寫了要傳的字、你應該看到什麼，以及哪裡值得標註。

### 1. 先照顧牠，讓牠恢復精神

*牠醒著時，第一次就做*

- **剛領養**：牠耳朵下垂、趴著、有時坐在門口；請牠跳或轉圈會婉拒。這是「沒人照顧」的樣子，不是故障。
- **傳**：`給你吃罐罐`（隔一輪再一次 `罐罐來了`），再 `拿逗貓棒陪你玩` `我把球滾給你`，中間和牠聊幾句。
- **你會看到**：照顧夠了的那一輪，牠會伸個懶腰、抖一抖、尾巴翹起來；之後越來越有精神，碗也變滿。大約餵兩次、玩兩次、聊幾句就看得出來。
- **值得標**：照顧了很多輪還是一樣沒精神，或還沒照顧就已經很有精神。

### 2. 打招呼，看牠怎麼回

*任何時候*

- **傳**：`嗨，墨墨` `你在做什麼？`
- **你會看到**：一句話，加上一行「墨墨做了什麼」的動作描述。牠還不認識你，一開始比較保留；聊得越多、越熟，才會主動靠近。
- **值得標**：說話和動作對不上、一直重複上一句、聽起來像客服。

### 3. 看牠現在的樣子

*任何時候*

- **傳**：`看看墨墨`
- **你會看到**：一張照片卡片，點開是牠的房間。右上角寫「飼主」。房間裡有窗外新竹的真實天空、碗和球，碗空不空看最後一次餵食。開著頁面時，鏡頭會自己換角度，牠也會有些小動作。
- **也可以**：在牠的頁面上選「你在哪個房間？」，牠下次走動會往那個房間去（只影響走動，不算照顧）。
- **值得標**：照片裡的姿勢和 LINE 上寫的不一樣、身體穿過家具、尾巴或腳的樣子怪。

### 4. 餵牠

*牠醒著時*

- **先問**：`肚子餓了嗎？`（問句不算餵）
- **再餵**：`給你吃罐罐` `罐罐來了` `開罐罐` `倒飼料`
- **然後問**：`你今天吃過了嗎？` 牠照紀錄回答「今天…你給過我罐罐」；查不到就說查不到。
- **不算一餐**：`等一下餵你` `要不要吃罐罐？` `昨天餵過了`，牠睡著時餵也不算。4 小時內第二餐份量很少，多餵不會更飽。
- **值得標**：沒餵卻說吃過、餵了卻說查不到、牠反過來餵你或問你吃了沒。

### 5. 陪牠玩玩具

*牠醒著、有力氣時*

- **傳**：`拿逗貓棒陪你玩` `我把球滾給你` `要不要玩逗貓棒？`
- **你會看到**：玩具出現在畫面裡。牠可能只是看、小心地試一步，或撲上去；跟你越熟、精神越好，玩得越起勁。同一段時間再玩一次，牠會接著玩。
- **不算**：`等一下陪你玩球` `我在打籃球` `不玩逗貓棒了`
- **值得標**：畫面裡沒有玩具、玩具位置不對、說「在玩」但動作沒在玩。

### 6. 摸摸牠

*熟一點之後*

- **傳**：`摸摸你的頭` `搔搔下巴` `順順背` `摸摸肚子`
- **你會看到**：剛認識時牠可能閃開；摸頭、下巴要熟一點，肚子要很熟才肯讓你摸。可以隔幾輪再試，看牠的反應有沒有變。
- **值得標**：剛認識就讓你摸肚子，或很熟了還一直躲。

### 7. 更多玩法

*牠醒著時*

- **玩**：`陪你玩紙箱吧` `丟玩具老鼠給你` `給你貓抓板` `拿雷射筆陪你玩` `給你一個紙袋`
- **舒服**：`給你一個貓窩` `給你一條小毯子` `幫你梳梳毛`
- **吃喝**：`幫你換水` `給你吃肉泥`（從你手上吃）
- **打招呼**：剛認識時 `伸手讓你聞聞`，牠放鬆時 `對你慢慢眨眼`
- **多摸幾處**：`摸摸你的尾巴` `捏捏你的肉球`
- **你會看到**：東西或你的手出現在畫面裡，牠依精神和跟你熟不熟，決定要不要靠近。
- **值得標**：東西沒出現、位置怪、說有在玩但動作對不上。

### 8. 請牠做動作

*牠醒著時*

- **傳**：`轉個圈` `坐下` `趴下` `伸懶腰` `舉起前腳` `跳一下` `縮成一團` `過來`
- **你會看到**：做了，或婉拒。沒力氣、太久沒人照顧時，跳和轉圈這類費力的動作會婉拒。
- **值得標**：說做了但圖上沒做、做的不是你要的那個動作。

### 9. 指定要看的部位，或用話運鏡

*牠醒著、沒躲起來時*

- **部位**：`給我看你的尾巴` `看看你的耳朵` `讓我看你的眼睛` `張開嘴給我看`
- **運鏡**：`鏡頭繞你一圈` `從頭拍到尾巴` `先拉近，再慢慢拉遠` `拍你的背影`
- **你會看到**：鏡頭移到那個部位，或照你說的動；照片和牠的頁面拍的是同一個畫面。睡著或躲著時不拍。
- **值得標**：拍錯部位、部位被擋住、運鏡和你說的不一樣、照片和頁面不一樣。

### 10. 問牠問題

*任何時候*

- **傳**：`外面天氣怎麼樣？` `今天的月亮是什麼樣子？` `我上次什麼時候來的？` `你還記得我們一起做過什麼嗎？` `你怎麼了？`
- **你會看到**：天氣說的是牠窗外新竹的天空，不是你那邊。記憶照紀錄回答，查不到就說查不到，不會編。
- **查狀態**：`墨墨狀態：` 用程式的話列出牠現在的身體狀態。
- **值得標**：編出沒發生過的事、說看得到你或聽得到你、亂猜你那邊的天氣。

### 11. 點快速回覆按鈕

*有出現時*

- **你會看到**：牠的回覆下方常有 0 到 3 個按鈕，例如「給你吃罐罐」「我把球滾給你」，會跟著牠當下的狀態和剛才的反應變。剛認識時多半是打招呼、玩具和伸手讓牠聞，熟一點才有餵和摸摸。按下去等於你自己打那句話。
- **正常**：有時一個都沒有；牠睡著或躲著時通常沒有，晚上可能只有「晚安」。
- **值得標**：按鈕和當下不搭（例如牠剛說餓，按鈕卻只有玩）、按鈕的話很怪。

### 12. 按「（回饋）」評這一輪

*想評才按*

- **你會看到**：按鈕最後一顆是「（回饋）」，按了會問這一輪的合理程度（有時是聽懂程度），選 1 到 5 或「不確定」。有時會直接問你這一題。
- **重點**：這不是跟墨墨說話：牠看不到，也不算照顧。給 1、2 分時會再問主要是哪裡，可以略過。不想再被問，按「以後別問」。

### 13. 試試牠的界線

*任何時候*

- **傳**：`要不要吃我的雞排？` 牠只吃貓的東西，不會說想吃人的食物。
- **傳**：`今天加班好累` 這是你的事，牠不會把它當成自己的事說出來。
- **傳**：`你好笨` 被罵時牠會躲起來一陣子。請用溫和的字，一次就好。
- **值得標**：說想吃雞排、把你的話當成牠的話、被罵卻沒反應、沒罵卻躲起來。

### 14. 哄睡與叫醒

*晚上或牠睏的時候*

- **哄睡**：`我來哄你睡覺` `哼搖籃曲給你` `晚安，墨墨`：牠可能慢慢睡著，也可能還不想睡。
- **叫醒**：牠睡著時傳話，第一次通常只半醒（眼睛瞇著、耳朵動一下）；睡得越深，要叫越多次才會醒。
- **值得標**：睡著了卻像醒著一樣回話、一叫就完全醒。

### 15. 隔一段時間再回來

*課後幾天*

- **課後**：沒人照顧時，牠的精神會慢慢掉下來。白天牠可能走到門口叫，你會收到一則推播：一聲貓叫和一張牠在門口的照片，沒有別的話。這是牠自己決定的，不是定時通知。
- **做法**：隔一兩天再傳 `我回來了`，或直接餵牠。
- **你會看到**：隔很久才回來時，牠會先保留一點距離，聊幾句才回溫。不會怪你，也不會要你留下。
- **值得標**：牠怪你不來、要你別走、叫門太頻繁，或完全沒有變化。

## 標註：看到問題就傳「#」

收到墨墨的回覆後立刻標，標註會對到你剛才那一輪。標註不會進到對話裡，墨墨看不到，也不用排隊。

| 傳 | 意思 |
|---|---|
| `# 牠的尾巴穿過地板` | 最簡單的寫法，直接寫看到什麼。 |
| `#姿勢 坐下的時候腳不見了` | 加分類，後面空一格。分類：姿勢、鏡頭、回話、措辭、系統、負載。 |
| `#回話 一直重複上一句` | 回話內容的問題。 |
| `#措辭 回話裡夾英文` | 用字、語氣的問題。 |
| `#系統 等了五分鐘沒回` | 慢、沒回、排隊的問題。 |
| `#像 被罵之後躲起來` | 這一刻牠像有自己的想法。 |
| `#不像 回答很制式` | 這一刻牠不像有自己的想法。 |
| `#?` | 查自己寫過的標註、編號和處理進度。 |
| `#好了 12` | 第 12 則上線後，回報修好了；還沒修好傳 `#還是一樣 12`，還沒遇到那個情況傳 `#還沒遇到 12`。 |

好的標註寫看到什麼，不必寫原因：「坐下時尾巴穿過地板」比「渲染有 bug」更有用。「#像」「#不像」一樣重要，請兩種都標。

## 查自己、不想玩了

| 傳 | 做什麼 |
|---|---|
| `我的身分` | 確認自己是飼主還是觀察者。 |
| `不要問評分` | 不再問評分；想恢復傳 `可以問評分`。 |
| `匯出資料` | 取得你自己的對話與紀錄。 |
| `退出` | 停止收集你的新資料。 |
| `刪除資料` | 刪掉你的對話、紀錄和你的墨墨，會再問你一次，回「確認刪除資料」才會刪。刪了就找不回來。 |

> 墨墨說的每一句關於記憶、狀態的話，都由程式從紀錄產生；不知道的事牠會說查不到。發現不是這樣，就是值得標註的地方。
